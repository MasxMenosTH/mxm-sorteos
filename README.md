# Sorteos Institucionales MXM

Versión estática para GitHub Pages.

Archivos necesarios en la raíz del repositorio:

- `index.html`
- `logo-mxm.png`
- `.nojekyll`

No requiere Node.js, npm, React ni backend.

## Publicación
En GitHub: Settings > Pages > Build and deployment > Source: Deploy from a branch.
Seleccione `main` y `/(root)`, luego Save.

## Datos
Los archivos Excel/CSV se procesan en el navegador. No incluya bases reales de clientes dentro del repositorio.
